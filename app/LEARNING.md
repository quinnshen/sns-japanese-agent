# 第三阶段：提前生成翻译与学习解析

本模块读取已有 ASR 句段，保存中文翻译、括号假名和关键拆解。它不录音、不调用 Google、不分析视频画面。扩展读取已保存结果，点击「展开解析」只改变本地显示，不调用模型。

在扩展 **0.5.4** 中，用户已确认旧会话释放后的新采集可以开始，以及新素材全流水线的基本体验可用。新约两分钟素材已完成 24 批采集和 3 个 Google 窗口，共 44 句；首轮 38 句解析通过，明确授权的 4 次定向修复后为 42/44 句。剩余 2 句的 ASR 存疑引用漏注音，未放宽校验或继续请求；原先通过的 38 句和 Google 转写保持不变。日语解释的内容准确性仍需抽查。

扩展 **0.6.0** 增加了明确的学习和复习入口、下一段、原区间重试、独立收藏和普通片段 7 天清理。新版路径已用离线测试验证，实际 Chrome 操作及长视频稳定性待验收。

旧后端缺少复习接口时，新版会提示重启本机后端，而不是显示成空列表或笼统的收藏失败。本机服务现已提供版本及复习能力信息；已有真实片段与收藏的数据接口已核对，读取不会调用云端。收藏的原句及解析保存在独立的私有目录，未加入版本库。

## 文本批次独立于音频窗口

- 每批最多 **6 个目标句段**，目标原文总量最多 **1800 字符**；整句不截断。过长单句返回安全错误码，等待调整，而不是悄悄截取。
- 另提供前后各最多 **2 句**文字语境，同批目标也包含在语境中。只为目标句生成结果。
- 转写仍在继续时，等目标组和右侧语境就绪再派发；转写最终完成时刷新最后一组。
- 已有句段的 ID 与 ASR 原文用于复用判断。视频时间映射后续完善时更新显示时间，不因此重发 GPT。
- Google 调度与 OpenAI 调度分别限流，保存新句段后即可通知下游；解析不占用 Google 的请求槽。

上传间隔、Google 识别窗口与 GPT 文本批次各自设计。改变录音 batch 大小无需同步改变 GPT 分组。

## 输出与校验

每句保存原文和独立的展示文本、自然中文、通常 1–4 条关键拆解，以及必要的语境说明和 ASR 存疑。学习提示沿用已约定的初级下册水平、动词变化、小句范围和口语语气要求。

- 原 ASR 文件只读。展示文本只能插入括号假名，不能改写原句；原有括号内容也必须保留。
- 日文汉字需要假名。拆解中的日文引用和动词形式同样校验；中文解释不作为日文逐字注音。
- 原句已完整注音时，可在本机把已有括号假名复制到完全匹配、尚未注音的日语引用。这个过程不推测新读音；同形多读、复合词边界不完整、原句有假名括号或引用已有部分注音时保留原样，继续交给校验判断。
- 逐句验证，保存合法邻句。个别注音错误、缺失或不通顺不会丢弃已完成的其他句子。
- 未通过校验的原文保留在本机 ASR 中，扩展只显示「学习内容待生成／需处理」状态，不把未注音的原句作为学习文本展示。
- 指示词和画面含义无法靠文字确认时明确保留不确定性。模型输出仍需人工抽查，格式校验不能证明语言解释一定正确。

请求使用 Responses API 的严格 JSON Schema；仍显式处理截断、拒绝和无效响应。[OpenAI Structured Outputs 文档](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)

## 配置与启动

默认纯本机采集，两个云端阶段分别启用。在被 Git 忽略的 `app/backend/.env.local` 中配置操作者自己的凭据和设置：

```dotenv
OPENAI_API_KEY=YOUR_OWN_OPENAI_API_KEY
OPENAI_MODEL=gpt-6-luna
ENABLE_CAPTURE_TRANSCRIPTION=1
ENABLE_CAPTURE_ENRICHMENT=1
ENABLE_LEGACY_PIPELINE=0
ENABLE_ENRICHMENT=0
```

真实密钥通过 `app/backend/configure_openai_key.py` 的隐藏输入保存，不写进扩展、命令历史或 Git。Google 使用操作者自己的项目和仓库外 ADC。重启本机服务后生效；新录音开始前，面板会提示启用的云端阶段。

所有入口使用同一个配置模块。新录音的自动解析需要两个阶段同时启用；只有学习开关为 1 时，仍可独立处理已有 ASR，但不会为新录音自动生成 Google 转写。OpenAI SDK 自动重试设为 0，响应使用 `store=False`；这不改变提供方账户的其他数据保留规则。

### 用已有转写离线准备

在仓库根目录执行，替换占位任务 ID：

```sh
CAPTURE_ID="YOUR_CAPTURE_ID"
app/backend/.venv/bin/python app/backend/capture_learn_cli.py \
  "app/data/captures/$CAPTURE_ID"
```

默认不调用 OpenAI，也不加载 Google 凭据；它规划文本批次并复用已保存结果。

如果修正了本机校验规则，可离线复验已经收到的响应，不重新付费生成：

```sh
app/backend/.venv/bin/python app/backend/capture_learn_cli.py \
  "app/data/captures/$CAPTURE_ID" --revalidate-saved
```

该模式保留原请求次数、响应、时间及已接受结果；没有可靠响应的未知请求仍需单独处理。它不能与付费、重试或预算修改参数组合。

### 限量真实验证

```sh
app/backend/.venv/bin/python app/backend/capture_learn_cli.py \
  "app/data/captures/$CAPTURE_ID" --run-openai --max-new-requests 1
```

`--run-openai` 是独立的明确付费入口，即使服务器自动开关为 0 也可执行。`--max-new-requests 1` 限制这次命令最多新增一次请求；确认后再次执行可处理下一组。成功句子始终复用。此命令不会重做 Google 识别。

## 恢复、重试与请求限制

派发前提交 SQLite 尝试记录，收到响应后先把原始响应写入私有文件并 `fsync`，再接受逐句结果。重启发现已保存响应时恢复，不再请求模型。只有未结束的派发记录、没有可靠响应时，标为 `unknown`。

| 状态 | 处理 |
|---|---|
| `queued` | 尚未请求 |
| `in_flight` | 本机已记录派发，等待结果 |
| `succeeded` | 此组目标句全部保存，可复用 |
| `partial` / `failed` | 部分结果非法，或明确失败；合法句仍保留 |
| `unknown` | 可能已经计费，本机没有可靠结果；不自动重试 |

已知失败或部分失败不阻止其他独立文本批次保存，但不会自动修复失败句。修正原因后可显式重试某一组，只重发尚未通过的目标句；本机把白名单校验代码转换为固定检查反馈，作为独立的可信消息发送，不把模型自己写的建议当成指令。反馈同样进入这次请求的指纹与记录。下面的批次序号 `0` 应替换为 `blocked_batches` 中的实际序号：

```sh
app/backend/.venv/bin/python app/backend/capture_learn_cli.py \
  "app/data/captures/$CAPTURE_ID" --run-openai --max-new-requests 1 \
  --retry-batch 0
```

未知结果还必须加 `--accept-duplicate-cost`，表示接受潜在重复费用。每组最多 **3 次尝试**。扩展没有自动重试或提高预算的按钮。

每个采集任务默认累计最多 **50 次 GPT 请求尝试**，跨重启持久保存；本次 CLI 限额另行生效。这是请求数量限制，不是美元账单硬上限。可以用 `--max-total-requests N` 收紧；提高已存上限必须同时明确指定 `--raise-request-budget --max-total-requests N`。默认重启不会自动提高先前收紧的限额。

停止录音任务或关闭自动开关会阻止后续派发；已经发出的请求可能仍会计费，收到的结果继续保存。服务重启后通过明确接口或 CLI 恢复已有任务，不在启动时遍历所有历史任务自动计费。

## 本机接口与展示

| 接口 | 行为 |
|---|---|
| `GET /captures/{id}/learning` | 只读指定片段的状态、区间与现有结果，不开始模型请求 |
| `GET /learning/library` | 列出有已验收学习内容的完整片段和收藏句子，不发云请求 |
| `POST /learning/favorites` | 通过采集 ID、句子 ID 和收藏状态保存或取消独立收藏，不发云请求 |
| `GET /learning/latest?url=...` | 保留旧版接口；新版面板由用户主动选择复习片段 |
| `POST /captures/{id}/learning`，JSON `{}` | 明确调度已有 ASR，要求学习开关为 1；可能产生 OpenAI 费用，不调用 Google |

扩展会跟进当前生成任务的进度，只显示通过校验的假名原句及中文。录音保存且有可用句子后即可开始精读；剩余解析可以继续生成。点击句子跳转到视频时间；没有有效视频时间的句子显示「时间待确认」并禁用跳转。普通的浏览器观测估算只在面板说明一次，采集期间禁止用句子跳转。

打开面板默认选择范围，确认「生成学习内容」才连接音频。精读的「学习下一段」预填当前片段的终点，用户确认新范围后才开始生成。录音中使用「停止生成」；如果广告打断录音，在播放器恢复播放、广告结束后选择「重试本段」，使用原区间创建新任务。

「复习」由用户主动打开，包含「最近片段」和「收藏句子」。同一视频的多个区间可以分别选择。收藏句子会独立保存原句、译文、解析及来源，普通片段清理后依然可读。Google 未完成或 GPT 结果部分失败时，进度如实保留，不把缺失内容标为完成。

这些接口沿用 loopback Host／Origin 检查，允许扩展及本机客户端；不是针对同机其他程序或扩展的身份认证。只供个人本机使用。

## 私有产物与验收

`app/data/captures/YOUR_CAPTURE_ID/learning/` 内保存 `state.sqlite3`、`batches/` 每次请求与响应、汇总 `result.json`、`status.json` 及工作锁。原始响应不改写，本机复制注音后的内容作为派生学习结果保存，可再次离线复验。目录权限为 `0700`、文件为 `0600`；随整个 `data/` 排除在 Git 之外。请求内容、响应、素材 URL、转写、令牌用量和提供方响应 ID 都属于本机运行数据，不复制进公开 fixture 或 issue。
